# Support

## Support level

`scadactl` is experimental software for evaluation on dedicated, explicitly
provisioned Linux systems. It is not supported for production or
business-critical workloads.

## Getting help

Use GitHub Issues for non-security bug reports, documentation problems, and
feature requests. Include:

- the `scadactl` version or full commit;
- operating system, kernel, Python, NVIDIA driver, CUDA, and storage-backend
  versions;
- relevant GPU and NVMe identities with sensitive information removed;
- installation method and configuration;
- deterministic reproduction steps; and
- relevant `scadactl doctor`, status, and domain logs.

There is no response-time, resolution-time, compatibility, or long-term-support
guarantee. Do not report vulnerabilities publicly; use the private NVIDIA PSIRT
channels in [SECURITY.md](SECURITY.md).
