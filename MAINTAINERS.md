# Maintainers

Maintainers are responsible for technical direction, review, issue triage,
security coordination, release evidence, and repository stewardship. Reviewers
provide domain-specific review but do not merge without maintainer approval.

Repository ownership is assigned to `@NVIDIA/scada-maintainers`. This team
supplies required CODEOWNERS and maintainer review. Current path ownership is
defined in [`.github/CODEOWNERS`](.github/CODEOWNERS).

Security reports must follow [SECURITY.md](SECURITY.md). The GitHub team and
repository access configuration are the authoritative membership sources.
